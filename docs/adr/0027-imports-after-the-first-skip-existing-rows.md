# Every legacy import after a cohort's first one skips the rows it already has

`scripts/import-legacy.mjs` runs bare once per cohort, for the import that creates it, and with `--skip-existing` every time after, because the bare form upserts every column its `ON CONFLICT` names and would silently overwrite corrections staff have since made in the app. Skipping is per row, so an existing project picks up nothing from a later export, and a cohort's first import is the cheap chance to get a row right. There is no standing exception: a mapping wrong for a whole cohort is fixed by a full upsert only as a one-off call against the staff edits it discards, with a dump taken first. Decided 2026-09-17.
