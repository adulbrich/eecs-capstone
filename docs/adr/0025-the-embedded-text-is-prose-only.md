# The embedded text is the project's own prose, not its categories or its program

`buildProjectEmbeddingSource` embeds the seven prose fields a proposer writes, title through license restrictions, and not the project's categories or programs. Both are already exact filters on the listing, the category vocabulary mostly repeats what the description says, a course identifier is not language, and the reader's interests the vector is compared against carry no taxonomy, so the sections added noise. Editing categories or programs therefore leaves the hash unchanged and `refreshProjectEmbedding` returns `"unchanged"`, and the backfill parity test pins the sections' absence in the `.mjs` too. Any change to this string re-embeds every project once at one paid Bedrock call each. Decided 2026-09-16 in #463.
