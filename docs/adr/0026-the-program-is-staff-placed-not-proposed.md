# The program is staff placed, not proposed

A project's programs are set by staff from the staff panel and by nobody else: `ProjectInput` carries no program, `createProjectAs` places nothing, and `updateProjectProgramsAs` is the only writer. Which course a project runs in depends on how many teams a term can carry and what is already placed, none of which a proposer can see, so this is the division #322 applied to the proposer and the categories. The cost is that a proposer who knows their course says so in the description or a note. A second writer beside the form's picker was rejected, because one value with two writers is how proposer and staff come to disagree unseen (#109). The openings flag, `accepting_applicants`, followed in #491 on the same reasoning and rides the same writer in the Programs and teams section; `teams_supported` is the exception (ADR-0032). Decided 2026-09-17 in #450.
