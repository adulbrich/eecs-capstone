# Kind of work replaces the Type facet

Project categories default to four types, Field, Technology, Industry and Kind of work, kept in `src/lib/default-categories.ts` with a one-sentence description each, because the descriptions are the definitions a model is given and the names it misread were the ambiguous ones (#31). Kind of work, exactly one per project, replaces the live Type facet, which answered three questions at once: Consultancy is who a project is for, New Product or Game is where it starts, and FOSS is a licence that holds for any of them. Staff had put Consultancy and New Product or Game on the same project. Migration 0043 moved Research into Kind of work and Web into Field: Web Development with their projects, and deleted Consultancy, FOSS and New Product or Game, whose projects are left for the categorization backfill. An open-source filter is not a category; if one is asked for, decide then between a column and a category. Every type stays discipline-neutral, so another department adds categories to Field and Industry, never a type. Decided 2026-11-12.
