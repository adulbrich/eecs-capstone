# Mentorship is the mentor address, and nothing else

A project's mentorship is `mentor_email`, one nullable column, staff-written and never public. Replaces ADR-0022, whose three-state `mentor_need` mostly served would-be mentors shopping the public listing and a "no formal mentor" notice the description can carry. Staff need to record who mentors a project, see which student-proposed projects have nobody, and match those to the volunteers on `/admin/mentors`, and a null answers all three; a mentor on a project that did not strictly need one is a fact, and an instructor running a team without an outside mentor records their own address. A staff-only state with no public face was rejected: it kept a column and a refusal for a distinction the null already draws. `/admin/projects` filters on `mentor_email IS NULL`. Decided 2026-09-14 in #402.
