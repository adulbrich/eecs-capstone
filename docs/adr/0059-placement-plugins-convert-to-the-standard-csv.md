# Placement plugins convert to the standard CSV

Placement has one standard CSV per dataset (projects, roster, bids), described in `src/lib/placement/formats.ts` and read by one parser each, and any other source shape reaches it through a plugin in `src/lib/placement/plugins/` that converts to that CSV text. Validation stays in one parser per dataset, and staff can download what a plugin made and re-upload it without the plugin. Plugins that emit the parsed model were rejected as spreading validation across every plugin, and plugins uploaded as code at run time as running unreviewed JavaScript beside FERPA records (ADR-0056); a mapping staff build in the page is data, and a plugin of its own (#735). The roster and bids are stored as uploaded and converted on every read, so a plugin fix reaches every saved workspace; projects are stored parsed, because staff edit them. Detection tries the standard format first, then each plugin in registry order, and a contract test fails a plugin that claims another's source. Decided 2026-10-03 in #698 and #733.
