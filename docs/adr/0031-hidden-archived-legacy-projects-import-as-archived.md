# The legacy projects the old portal hid are imported as `archived`, and so are public here

The 146 retired legacy projects that the old portal both archived and hid are imported as `archived`, and so are public here by link and through the archived filter. On an archived row the old portal's hidden flag was inert, and it recorded only whether a project had been published before it retired, not a decision to hide it. `approved` was rejected because it claims they await publication and has no edge to `archived`, and soft deleting was not available because `deleted_at` is not in the importer's upsert. Staff can archive and soft delete any that should not be public. Decided 2026-09-18.
