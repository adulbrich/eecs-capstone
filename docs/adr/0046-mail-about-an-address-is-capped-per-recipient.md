# Mail about an unproven address is capped per recipient, and fails open

`reserveVerificationMail` in `src/server/_internal/verification-sends.ts` caps mail about an address per recipient, counted in `verification_sends` by recipient and kind, because a per-sender limit says nothing about whose inbox fills and campus NAT makes a sender address meaningless (ADR-0039). Each kind has its own budget, so spending one cannot silence another; `sign-in-code` is the only kind left since #576 (ADR-0047). The counter fails open: what it gates is somebody's only way into their account, and a counter that cannot answer is a transient blip. Decided 2026-09-21 in #554.
