# The catalog is shareable but not indexed

Every catalog page carries `<meta name="robots" content="noindex, follow">` while `public/robots.txt` stays permissive. A project page carries a contact name and address published for a reader rather than a search index, and hundreds of legacy imports would outrank the current term. A `Disallow` in `robots.txt` was rejected because the chat preview scrapers honour it, which would kill the link previews; `noindex` is read only by indexers. The landing and privacy pages stay indexable. Chat unfurls are the only consumer of the `og:` tags, which must survive server rendering and are asserted against an anonymous SSR fetch. Nothing here limits what an anonymous reader can fetch. `NOINDEX` in `src/lib/social-meta.ts` is the one spelling, and a page out of the index for a term does not return the moment it goes.
