# Similar projects float below `xl` and sit beside the text from it

The project page lists up to five similar projects (#614) in three forms, one per width tier, all in `SimilarProjectsLayout` (`src/components/similar-projects.tsx`): from `xl` a sticky aside in a second grid column, between `md` and `xl` a card fixed at the bottom right that collapses to a labelled button, and below `md` an icon button at the bottom right that opens the list in a bottom `Sheet`. It is the second sanctioned `xl:` use after the listing filters ([ADR-0020](./0020-listing-filters-in-a-left-aside-from-xl.md)), and the arithmetic does not land on the breakpoint the way that one does: the 768px text column, a 32px gap, an 18rem aside and 64px of padding make 1152px, which `lg` (1024) cannot hold, and `xl` is the smallest existing tier above it; a custom breakpoint would have added a tier. The second column is reserved at `xl` whether or not the list arrives, because the list is a client query that lands after the page and a column appearing then would shove the text sideways; the cost is that a page with nothing similar (a draft, an unplaced project) sits left of centre at `xl`. The floating card covers the bottom right of the text between `md` and `xl`, where the column fills the width, which is why it collapses and why a collapse is remembered in `localStorage` across project pages; the phone form starts collapsed because a card over a 375px column hides most of it. The floating control sits in the corner Sonner toasts use, and the toasts stay there, over it, for the few seconds they show. The list is project to project and the same for every viewer: published, accepting applicants, sharing a program with the viewed project, nearest by cosine distance computed in Postgres, with no score shown. Decided 2026-09-23.
