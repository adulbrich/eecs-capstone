# Similar projects float below `xl` and sit beside the text from it

The project page lists up to five similar projects through `SimilarProjectsLayout` in `src/components/similar-projects.tsx`, in three forms: from `xl` a sticky aside in a second column, between `md` and `xl` a bottom-right card that collapses to a button, and below `md` an icon button opening a bottom `Sheet`. It is the second sanctioned `xl:` use after ADR-0020: the 768px text column, the gap, the 18rem aside and the padding make 1152px, which `lg` cannot hold, and a custom breakpoint would add a tier. The column is reserved at `xl` even when the list is empty, because the list is a client query and a late column would shove the text sideways, so a page with nothing similar sits left of centre. The floating card covers the corner of the text, so a collapse is remembered in `localStorage`, and the phone form starts collapsed. The list is the same for every viewer: published, accepting applicants, sharing a program, nearest by cosine distance, with no score shown. Decided 2026-09-23.
