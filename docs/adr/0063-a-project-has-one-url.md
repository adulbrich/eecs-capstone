# A project has one URL

`projects.url` holds one http or https link or nothing, checked by `projectUrlSchema` in `src/lib/project-url.ts` on the form and the server (#776). zod's `.url()` had let a proposer save six links separated by spaces, which rendered as one broken link. A list of links was declined: proposers who gave several usually labelled them, which is prose, and the description's Markdown already links them. More than one means whitespace or a link right after a comma, semicolon or bar, not any second `://`, which an archive.org snapshot holds. A bare domain is refused rather than prefixed on save. A value stored before this that fails the rule shows as plain text, and its project cannot be saved until it is fixed; migration 0041 gave the bare domains `https://`. `scripts/import-legacy.mjs` still writes the value as given. Decided 2026-10-07.
