# A project has one URL

`projects.url` holds one http or https link or nothing, checked by `projectUrlSchema` in `src/lib/project-url.ts` on the form and the server (#776). zod's `.url()` had let a proposer save six links separated by spaces, which rendered as one broken link. A list of links was the alternative: an array column or a table, a repeatable form field, and changes to the admin column, the CSV export and the importer. It was declined because the proposers who gave several links usually labelled them, which is prose, and the description's Markdown already turns pasted links into links. The field's hint and its error send extra links there. A value written before this release that fails the rule shows as plain text, not a link, until someone edits it, and editing it means fixing it first; migration 0041 gave the bare domains `https://`. Decided 2026-10-07.
