# The task outlasts the load balancer's idle timeout, and a wrapper is how

`src/lib/_internal/keep-alive-timeout.ts` sets Node's `keepAliveTimeout` to 65 seconds, above the ALB `idle_timeout` of 60 that `infra/ecs.tf` states, because Node's 5 second default closed pooled connections the balancer went on reusing, and a request dispatched onto one returned a 502 with no target status (#545). Lowering the ALB timeout instead would trade 502s for 504s, since it also bounds a target's first byte. The option is unreachable through Nitro's configuration, so a Nitro plugin wraps `http.createServer` at boot; a project copy of Nitro's entry would fork framework internals that go stale silently, where the wrapper goes stale loudly. `src/lib/__tests__/keep-alive-timeout.test.ts` reads `idle_timeout` from `infra/ecs.tf` and holds the Node value above it, and `scripts/loadtest/pooled-connection-reuse.mjs` reproduces the defect locally. Decided 2026-09-21.
