# Specs live in GitHub issues; the superpowers workflow is for a few large features

Ordinary work starts from a `ready-for-agent` or `ready-for-human` issue carrying an agent brief (current behaviour, desired behaviour, key interfaces, acceptance criteria, a table of which fields are public and who edits them) and ends in a pull request that is the plan, reviewed by `mattpocock-skills:code-review` until a pass raises nothing unanswered. The brainstorm, spec and plan workflow under `docs/superpowers/` is reserved for the few large new features that need a design document; everything before 2026-09 went that way and it is not the path for a bug or a bounded enhancement. Briefs name file paths on purpose: here they are the grep targets the codebase is organized around, and issues are picked up within days.
