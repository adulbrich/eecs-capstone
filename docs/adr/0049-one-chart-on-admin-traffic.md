# One chart, on `/admin/traffic`, through shadcn `chart`

`/admin/analytics` uses no charting library, and `/admin/traffic` has one chart: page views and visits per day, drawn by shadcn's `chart` on Recharts. Analytics figures are stocks or counts over a range, which a number states better than a picture; traffic asks about a shape over time, whether a publication or a course link produced a spike, which ninety daily numbers do not answer at a glance. shadcn's `chart` won because it takes its colors as CSS custom properties, so the series follow dark mode with no hex code in a component. It was trimmed to a container, a tooltip and a legend, and series colors reach it through the container's `style`, removing upstream's `dangerouslySetInnerHTML`. The SVG is hidden from assistive technology and the same numbers render as a table only a screen reader reaches. Decided in #512.
