# One chart, on `/admin/traffic`, through shadcn `chart`

`/admin/analytics` still uses no charting library, and `/admin/traffic` (#592) uses one chart: page views and visits per day across the date range, drawn by shadcn's `chart` component on Recharts. The rule on #34 held because every analytics figure is a stock or a count over a range, which a number states better than a picture. Traffic is the case that earns an exception, because its question is a shape over time: whether reading rose when a term's projects were published, whether a link from a course page produced a spike or a plateau, and a column of ninety daily numbers answers neither at a glance. shadcn's `chart` over any other library because it takes its colors as CSS custom properties, so the series draw in `var(--chart-1)` and `var(--chart-3)` and follow dark mode and a rebrand the way every other surface does, with no hex code in a component (`docs/UI-CONVENTIONS.md`, "Color tokens"). It was added with the shadcn CLI and trimmed to a container, a tooltip and a legend; the one change of substance is that series colors reach the chart through the container's `style` rather than a generated `<style>` tag, which removes upstream's `dangerouslySetInnerHTML`. The SVG is hidden from assistive technology and the same numbers render as a table only a screen reader reaches. Every other figure on the page is a number or a table. Decided in #512; built in #592.
