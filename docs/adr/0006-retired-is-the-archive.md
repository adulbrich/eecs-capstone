# Retired is the archive and staff-only; hard delete is narrow

An inventory item that has ever been requested cannot be deleted, because `inventory_request_items.item_id` is `ON DELETE RESTRICT` and the request history is the point. So retired is the archive: excluded from every listing by default, staff included, reachable only through the retired-only switch on the admin table and by URL for staff. One rule, `canSeeRetired` in `src/lib/inventory-visibility.ts`, feeds both the listing's status set and the single-row gate, because the two hand-written versions had disagreed and left staff able to open a retired item they had no way to find. Hard delete is permitted only for an available or retired item with no request lines, and the impl pre-checks rather than let Postgres raise the constraint.
