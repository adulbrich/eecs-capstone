# Closed days of traffic are rolled up into visits

Amends ADR-0048, which derived visits at query time and never stored them: `/admin/traffic` reads a closed day's visits from `traffic_visits`, one row per visit, filled from `traffic_events` by the same query that derives today's, because two window passes over a 90-day range took over 500 ms against a 200 ms budget. A closed day never changes, so it is rolled up once, on the first page load after local midnight plus a two-minute margin, under a transaction-scoped advisory lock. The public endpoint still only inserts, and the table is derived data that can be truncated and rebuilt under whatever definition then holds. A rollup row keeps no hash, address or person: the day, entry page and referring host, country, browser, device, pages with counts, listing filters, and whether it was that visitor's first visit of the day, which keeps distinct visitors countable. The office's local date is a generated `day` column held to `OFFICE_TIME_ZONE` by a test. Decided in #592.
