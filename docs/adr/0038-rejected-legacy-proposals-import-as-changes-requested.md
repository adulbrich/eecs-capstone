# Rejected legacy proposals import as `changes_requested`

Rejected proposals in the old portal that staff intend to rewrite here import as `changes_requested`, the status this vocabulary has for a proposal turned down that its proposer may still fix. `draft` was rejected because it says the project was never submitted. Neither status reaches a public path, staff can edit the rows on arrival, and a proposer can once their address links them (ADR-0007). The importer writes no status history, since ADR-0004 gives that table one writer, so the rows carry no change-request comment and the reason goes in `notes`. A description over the form's 5,000 character cap imports but cannot be saved, so rewriting it to fit is part of the import. Rejected rows nobody plans to touch stay in the portal. Decided 2026-09-20.
