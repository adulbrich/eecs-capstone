# The listing carries an excerpt, not the prose

The four reads behind the project card and the public table (the listing, My Projects, Mentoring on My Projects and bookmarks) carry no prose field, only `excerpt`: the description stripped of markdown and cut to 320 characters on a word boundary, or null (#761). This reverses #78, which carried every public field so table view could offer each as a column; nobody read them in a clamped cell, and they were 70 KB of a 175 KB `/projects` page. Similar projects cuts its excerpt with the same function. Table view receives the excerpt from the shared loader and renders none of it, about 6 KB a page, which is accepted rather than branching the read by view. Table view cannot show prose without a new read. A prose field added to a project is seen on the project page or through its own read path. Tabs open across the deploy show cards without text until reloaded. Decided 2026-10-06.
