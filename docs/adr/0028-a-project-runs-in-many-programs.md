# A project runs in many programs

A project runs in a set of programs, `project_programs`, rather than in one `projects.program_id`, because a course offered both in Corvallis and on Ecampus is one proposal and one team filed under two courses, and the single column hid it from one program's listing. The set is unordered, shown in `course_id` order, and zero, one or many are ordinary. `teams_supported` stays one integer shared across the set; per-program counts are #469. The accepted cost is that a shared project counts its whole `teams_supported` in each program's analytics, so per-program figures do not sum to the total, and the staff panel warns rather than refuses when programs outnumber teams. A nullable primary program beside the set was rejected as the single value back again. Reads render the set through `projectProgramsList` or `projectProgramsText` and filter through `runsInProgram` or `inNoProgram`. Decided 2026-09-17 in #462.
