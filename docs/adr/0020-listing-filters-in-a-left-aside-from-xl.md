# Listing filters sit in a left aside from `xl`, and in a sheet below it

A listing keeps its search on top at every width and puts the controls that narrow it in a left aside from `xl` and in a left `Sheet` below, opened by a Filters button carrying the count of what is on; sort and the card/table toggle stay beside the search, because they order and display rather than narrow. The tier is `xl` rather than `lg` because the 896px card column, the 18rem aside, the gap and the page padding make 1280px exactly, so the cards never shrink. That adds a third responsive tier to a design system that kept two, confined to `ListingLayout` in `src/components/listing-layout.tsx`. The filter form renders twice, in the aside and in the sheet, so a filters component must be safe to mount twice and give every control `w-full`. The admin filters left `AdminDataTable`'s toolbar slot rather than the table growing a filters slot. Decided 2026-09-12 in #350.
