# Access logs keep raw addresses, and the retention rule is the control

ALB and CloudFront access logs record each client's full IP into one private encrypted bucket that deletes objects after 30 days, the same number as the CloudWatch log group. That is the opposite of the traffic writer, which hashes the address (ADR-0048), and neither is a precedent for the other: an analytics table any staff member reads needs no address, while an access log exists to answer which request came from where during an incident, which a hash cannot. Retention is the control, and it expires rather than transitions, because an address in cheaper storage is still an address. CloudFront uses standard logging v2, since the legacy `logging_config` needs ACLs on a bucket of visitor addresses; its delivery prefix is fixed, so the bucket policy is scoped by principal and account. Retention is a variable, and raising it lengthens how long visitor addresses are kept. Decided 2026-09-20 in #523.
