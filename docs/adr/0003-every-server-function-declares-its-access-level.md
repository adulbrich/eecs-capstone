# Every server function declares its access level

There is no global middleware, so the guard an endpoint carries is the only one it has, and no grep can tell a gated endpoint from an ungated one. Rather than detect the level, `src/server/__tests__/access-contract.ts` declares it, one line per endpoint, and its test fails on an endpoint with no line, a line naming no endpoint, a change to the set declared public, or a `createServerFn` in a shape the scan cannot parse. The declaration is the effective level, so a transition endpoint whose rules decide per role is still `staff`. A read is staff-only when its query reaches a column of somebody's account, by projection or by join, so no public fragment reaches `user`. A classification kept only in prose cannot fail, and two public endpoints shipped ungated for three months under one.
