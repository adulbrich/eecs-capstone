# Custom requests reuse the request envelope, and an envelope holds one kind of line

A custom request, an ask for equipment the inventory does not hold, is an `inventory_requests` row with one `inventory_custom_lines` row per thing rather than a table of its own, so the staff queue and `/my/items` group both kinds by one envelope shape. An envelope holds item lines or custom lines, never both, which `/inventory/request` guarantees as the only writer of custom lines; a group action then takes one pickup date on a borrow list and nothing on a custom request. The cost is that an envelope no longer implies an `inventory_request_items` row, so a new join that assumes it silently drops every custom request. Fulfilled items link through `inventory_custom_line_items` with `RESTRICT` on the item (ADR-0006), which also lets `/my/items` file the resulting hold under its line.
